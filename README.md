# Palestine — Île Vivante

Simulation 3D en français d'un village insulaire méditerranéen de 50 habitants qui pensent, parlent et décident par eux-mêmes avec un modèle de langage.

- Jouer en ligne : https://ile-vivante.vercel.app (clé Groq gratuite demandée au premier lancement)
- Code, fonctionnement et installation : [`palestine-ile-vivante/`](palestine-ile-vivante/README.md)

L'ancien prototype de banque digitale (`index.html`, `app.html`) a été retiré ; il reste disponible dans l'historique Git.
